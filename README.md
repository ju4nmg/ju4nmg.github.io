# ju4nmg.github.io

Personal website and portfolio of Juan Manuel Gimenez — Site Reliability Engineer (SRE) & DevOps Engineer.

Built with HTML5, CSS3, JavaScript, Bootstrap, and hosted on GitHub Pages.

## Site Structure
- `index.html` - Main portfolio page (About, Skills, Experience, Contact)
- `css/` - Custom styles and dependencies
- `js/` - Interactive portfolio scripts
- `images/` - Portfolio media assets
- `.github/workflows/` - CI/CD and security audit workflows
